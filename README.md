# بوت Raghad — اختبارات برمجة على تليجرام

بوت بسيط بيقدم أسئلة اختيار من متعدد في JavaScript وPython وأساسيات برمجة عامة.

## 1. عمل البوت في تليجرام
1. افتح تليجرام وابحث عن **BotFather**.
2. ابعت `/newbot` واتبع الخطوات (اسم البوت + username ينتهي بـ `bot`).
3. هياخدك التوكن — انسخه.

## 2. تجهيز المشروع
```bash
npm install
```

## 3. ضبط التوكن
انسخ ملف `.env.example` وسمّيه `.env`، وحط التوكن جواه:
```
BOT_TOKEN=1234567890:ABCDEF...
```

## 4. تشغيل البوت
```bash
npm start
```

هتلاقي في الكونسول رسالة:
```
✅ Raghad bot شغال دلوقتي...
```

افتح تليجرام وابعت `/start` للبوت.

## الأوامر المتاحة
- `/start` — بداية جديدة + اختيار تصنيف
- `/menu` — عرض قائمة التصنيفات تاني
- `/score` — عرض نتيجتك في الاختبار الحالي

## إضافة أسئلة جديدة
كل الأسئلة في ملف `questions.js`. تقدر تضيف تصنيف جديد أو أسئلة جديدة بنفس الصيغة:
```js
{
  question: "نص السؤال",
  options: ["اختيار 1", "اختيار 2", "اختيار 3", "اختيار 4"],
  correctIndex: 0 // رقم الاختيار الصح (يبدأ من صفر)
}
```

## ملاحظة عن الاستضافة
البوت شغال بنظام polling، يعني لازم يفضل الجهاز اللي شغال عليه شغال (سيرفر أو كمبيوترك).
لو عايز يفضل شغال 24/7 تقدر تستضيفه على أي سيرفر Node.js زي Railway أو Render أو VPS بسيط.
